# Architecture Decision Records (ADRs)

One file per decision worth remembering later — why we automated a step a particular way, what alternative we rejected and why. Not a design doc; a paragraph or two is usually enough.

Naming: `NNNN-short-title.md`, numbered sequentially. Never renumber or delete a past ADR — if a decision is reversed, add a new ADR that supersedes it and say so in both files.

Start from `0000-template.md`.
