# Checklists

The sign-off checklists currently used to confirm an onboarding is actually complete before go-live — the human-facing counterpart to the automated validation in `../02-target-state.md`. These describe what people check today; if a checklist item can be automated, that's a candidate for a new skill, but the checklist itself stays as the source of truth for what "done" means until it's fully replaced.

Name files after what they gate: `static-data-signoff.md`, `go-live-signoff.md`.
